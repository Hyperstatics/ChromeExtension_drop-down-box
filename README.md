# Google Suggest Collector

一个轻量级的 Chrome 扩展，用于采集 Google 搜索下拉框建议词。支持 API 自动采集和页面 DOM 抓取两种模式，结果可一键复制或导出 CSV。

## 功能特点

### API 采集模式
- **统一采集模式**：通过「深度」参数控制采集层级
  - `0` = 只获取一次建议（原简单模式）
  - `1~5` = 递归挖掘包含主关键词的长尾词
- **可配置请求间隔**：自定义每次请求之间的等待时间，降低被限流风险
- **指数退避机制**：遇到请求异常时自动翻倍延迟，保护 IP
- **可选结果过滤**：默认显示所有建议；取消勾选「不过滤」后只保留包含主关键词的建议词

### 页面抓取模式
- **从当前页面抓取**：直接在 `google.com` 搜索页读取已渲染的下拉框建议
- **不触发额外请求**：完全绕过 API 限流，适合精准采集
- **前后缀都能抓**：取决于你在搜索框中输入的内容和光标位置，Google 显示什么就抓什么
- **动态注入兜底**：如果扩展重新加载后 content script 未注入，background 会自动尝试重新注入

### 通用功能
- **导出方式**：支持一键复制全部结果，或导出为 CSV 文件
- **Side Panel 交互**：点击扩展图标即可在侧边栏打开，不遮挡当前页面

## 安装方法

1. 下载或克隆本仓库到本地
2. 打开 Chrome，访问 `chrome://extensions/`
3. 开启右上角「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择项目根目录即可

## 使用说明

### API 采集模式

1. 在任意网页点击工具栏的扩展图标，打开右侧 Side Panel
2. 在「API 采集模式」输入「关键词」
3. 设置「深度」和「间隔（秒）」
   - 深度建议 `0~5`，热门词深度 2 就可能产生上百条结果
   - 间隔建议 `2.5` 秒以上，网络不稳定时可适当加大
4. 点击「开始采集」，等待结果加载
5. 采集过程中可随时点击「停止」中断
6. 使用「复制全部」或「导出 CSV」保存结果

### 页面抓取模式

1. 打开 `https://www.google.com`
2. 在 Google 搜索框中输入关键词，**不要按回车**，等待下拉建议框出现
3. 点击扩展图标打开 Side Panel
4. 在「页面抓取模式」中输入用于过滤的关键词（留空则显示所有抓取到的建议）
5. 点击「从当前页面抓取」
6. 抓取到的建议词会显示在结果区，只保留包含你输入关键词的项

## 注意事项

- **网络环境**：API 模式直接请求 `suggestqueries.google.com`，请确保网络可以正常访问 Google 服务
- **限流保护**：Google 对频繁请求有限制，建议保持合理的间隔时间；如果遇到异常，扩展会自动触发指数退避
- **递归收敛**：不同关键词的扩展规模差异很大，热门词在深度 2 时就可能有几十到上百条结果，建议从小深度开始尝试
- **数据安全**：所有采集仅在本地进行，不会上传任何数据到第三方服务器

## 运维与维护

- **页面抓取模式的稳定性**：该模式依赖 Google 搜索页的前端 DOM 结构（主要是 ARIA 属性 `role="listbox"` 和 `role="option"`）。Google 的前端代码可能不定期更新，若某天抓取失败或返回空结果，通常意味着 DOM 选择器需要同步调整
- **扩展重新加载后**：如果已经打开的 Google 页面在扩展刷新前就已存在，content script 可能未重新注入。此时页面抓取模式会自动尝试重新注入脚本；如仍失败，手动刷新 Google 页面即可恢复
- **API 模式限制**：若长期大量请求导致 IP 被临时限制，建议增大间隔时间或切换至页面抓取模式
